# Job Board – Next.js

A job board built with Next.js App Router using the Remotive public API.

## Features
- Server-side data fetching with ISR
- URL-based filtering (search, category, limit)
- Client-side UI state
- Job detail pages with external attribution
- API-compliant third-party integration

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Data Source
Job data provided by Remotive.com
